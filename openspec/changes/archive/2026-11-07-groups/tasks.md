## Workflow follow-up

- Коммит и пуш в ветку `groups`, PR в main. В PR едет и новый `CLAUDE.md`.
- Автовлитие по `CLAUDE.md` включается сразу после PR. CI на PR пока нет, поэтому `gh pr merge --auto --squash` может оказаться недоступным: тогда сказать владельцу и ждать решения.
- Проверка перед merge пока только локальная: на PR ничего не запускается, а merge сразу запускает выкатку.
- После merge проверить выкатку: зелёный smoke `/health`, на https://app.chigabugadaga.ru видно пять готовых групп, контакты на месте.
- Архивировать изменение (`/opsx:archive`) после того, как фича принята.
- Позже, отдельно: e2e на Playwright и CI на PR.
