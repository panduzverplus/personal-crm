# Tasks

Код приложения пишем по TDD: сначала тест, он красный → код → тест зелёный. Там, где в задаче написано «тест», он пишется и запускается до кода. Тесты на базу и e2e идут на настоящем Postgres из Docker: перед ними `pnpm db:up`. Каждый сценарий спеки — свой тест: чистая логика проверяется в Vitest, поведение на экране — в Playwright.

## Workflow follow-up

- После «Коммить и пуш»: коммит в ветку `birthdays`, PR в `main`, автовлитие (`gh pr merge --auto --squash`) после зелёного CI.
- Миграция только добавляет колонки, существующие данные не меняет: показывать её до merge не требуется (правило `CLAUDE.md`).
- После выкатки на тест-стенд — проверить блок и поле на стенде; прод — только по запросу владельца.
